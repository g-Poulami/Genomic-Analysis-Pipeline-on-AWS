INSTALLATION QUICK START
================================================================================

Prerequisites:
- R 4.0+
- Docker and Docker Compose (optional, for local dev)
- AWS CLI v2
- Git

Step 1: Clone Repository
  git clone <repository-url>
  cd genomic_pipeline

Step 2: Install R Packages
  Rscript -e "renv::restore()"

Step 3: Configure AWS
  aws configure

Step 4: Start Services (Optional - for local dev)
  docker-compose up -d

Step 5: Run Pipeline
  Rscript scripts/run_pipeline.R SAMPLE_001 s3://bucket/sample.vcf.gz EUR

For detailed AWS setup (S3, RDS, Lambda), see README.md
