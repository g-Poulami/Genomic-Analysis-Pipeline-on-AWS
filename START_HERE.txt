QUICK INSTALLATION (30 MINUTES)
================================================================================

Prerequisites:
  - R 4.0+ 
  - AWS CLI v2
  - Git
  - Docker (optional)

Steps:

  1. Clone repository
     git clone <url>
     cd genomic_pipeline

  2. Install packages
     Rscript -e "renv::restore()"

  3. Configure AWS
     aws configure

  4. Start local services (optional)
     docker-compose up -d

  5. Run test
     Rscript scripts/run_pipeline.R TEST sample.vcf.gz EUR
